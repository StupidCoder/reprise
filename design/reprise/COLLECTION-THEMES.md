# Reprise collection themes

Three visual concepts generated with the built-in image_gen tool, using `library.png` as the common layout reference. No app code was changed. Catalog labels derive from the local project catalogs; six representative entries per screen, not complete collection inventories. Planned, partial, puzzle-only and import-only entries are distinguished where shown. Artwork is interpretive, not imported game data.

Shared structure: Reprise identity, search/import bar, collection sidebar, three-column grid, platform labels and selected-game Details bar. Palette, heading motifs, illustrated covers and selection accents vary by collection. Proposed motion character is not demonstrated by these static mockups.

Files: `sonic-collection.png`, `layton-collection.png`, `commodore-collection.png`.
