# Reprise 0.1.0

The first public release of Reprise: classic games, rebuilt and revealed.
Clean C++ game re-implementations share one portable SDL 3 launcher, with modern
conveniences and a look behind the curtain through development stories,
illustrated technical articles and live lessons.

## In this release

- A library of 26 titles: 13 C64/Amiga games, four Sonic games, six Professor
  Layton adventures, Spy Mouse, Captain Toad: Treasure Tracker and Astro Bot
  Rescue Mission. Support ranges from asset viewers to games playable through
  their endings; see the [game-by-game support table](https://github.com/StupidCoder/reprise/blob/v0.1.0/README.md#what-works-today).
- Portrait and landscape browsing, collection themes, game artwork, development
  stories, asset viewers with zoom/pan and animated 3D models.
- Persistent quick saves with screenshots and Continue where supported, shared
  options, GPU VHS filtering, and game-specific widescreen, smooth motion,
  cheats, touch and tilt controls.
- Illustrated lessons for Bruce Lee, Marble Madness, Stunt Car Racer and
  F/A-18 Interceptor, including interactive demonstrations where appropriate.
- Import individual game images or entire collections from stored/deflated
  ZIP and ZIP64 archives, including multi-disk games. Large images are streamed;
  per-file failures are reported without discarding successful imports.

## Downloads

- **Reprise-macOS-arm64.zip**: Apple Silicon Macs. Extract and open Reprise.app.
  The app is ad-hoc signed, **not notarized**; macOS may require approval in
  System Settings → Privacy & Security. Intel Macs are not supported by this download.
- **Reprise-Android-arm64.apk**: ARM64 Android 8 or later. Install by sideloading.
  It retains the existing shared debug signing key and debuggable configuration;
  this is not a Play Store package. It can update earlier CI builds signed with
  the same key. Keep existing app data when updating.
- SHA-256 checksums and Android build metadata accompany the downloads.

## Before playing

Supply your own supported original game images. No commercial game images or
imported asset packs are included. ZIP support does not make unsupported image
revisions or additional games compatible. Choose **Import game**, then a game
image or collection ZIP; open its card to start playing or explore documentation.

This is an early release with uneven game coverage. Astro Bot currently offers
asset exploration, not gameplay. Captain Toad covers the first four reconstructed
courses; Azran Legacy has no playable story in Reprise. Sonic Advance supports
Sonic's main adventure, with other modes still incomplete. Input support varies:
some games need physical controls, and touch support is not universal. Individual
game plans document remaining bugs and reconstruction/validation gaps.
